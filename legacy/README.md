# Original source reference

These files preserve the uploaded first-party scripts and pages for comparison. They are **not the supported entry points**: use `wechat/`, `matlab/` and `src/ecg/`.

The old WeChat chart/Excel dependencies, account-specific configuration and Git history were deliberately not copied. Some pages therefore cannot run in isolation. Original MATLAB script encoding and hardcoded paths are preserved here. `wavelet_original.m` is the former `wavedec.m`, renamed to avoid shadowing the MATLAB toolbox function; its contents are unchanged.

The old screens and comments may claim disease warnings or display placeholder history. Those features are not treated as a validated backend or diagnostic algorithm. See `docs/source-audit.md` for what was rebuilt and what is unavailable.
