# Original project image collection

These are figures and photographs from the supplied project archives, selected for the public project showcase. They show the original team's hardware, mechanical concepts, PCB work, software and development activities. No generated product imagery or stock photographs are used.

Photos have been oriented and compressed for web delivery, retaining their aspect ratios. Small CAD screenshots retain their original resolution. See [visual source manifest](../../docs/visual-sources.json) for source locations, preparation steps and source/published hashes.

Original team members retain credit for their work. These images do not provide editable CAD, fabrication files or independent performance certification. Administrative documents, contact details and member portrait collections are excluded.
